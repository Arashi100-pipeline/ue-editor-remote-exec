# Changelog

All notable changes will be documented in this file.

## 0.1.0 - 2026-09-01

- Added the independent Rust Remote Execution transport.
- Added exact project, PID, creation-time, and in-editor identity verification.
- Added isolated script injection and ordered single-connection plans.
- Added safe attach, process-local launch, consent-gated relaunch, and graceful close.
- Added loopback-only networking, dynamic callback ports, response limits, and
  non-retriable `outcome_unknown` handling.
- Added Python and Rust tests, CI, security documentation, and release packaging.
- Added a repository-root, one-prompt Codex installation contract and first-run
  dependency setup.
